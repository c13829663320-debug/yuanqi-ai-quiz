# 元启AI社互动抽题系统

## 部署到 GitHub Pages
1. 将本包内的 `index.html` 和 `.github` 文件夹上传到仓库 `c13829663320-debug/yuanqi-ai-quiz` 的 `main` 分支根目录。
2. 打开仓库 Settings → Pages，将 Build and deployment 的 Source 设为 GitHub Actions。
3. 在 Actions 页面等待 `Deploy static site to GitHub Pages` 工作流成功。
4. 成功后访问 https://c13829663320-debug.github.io/yuanqi-ai-quiz/

注意：上面的访问地址只有在首次部署成功后才会生效。
